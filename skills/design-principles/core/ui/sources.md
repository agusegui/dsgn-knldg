# UI Module — Sources

References informing the patterns and principles in this module.

---

- **Impeccable** (Paul Bakaus) — `github.com/pbakaus/impeccable`
  AI design vocabulary system. Contributed the 8-state framework for interactive elements,
  the hover/focus distinction, undo-over-confirmation pattern, and visual cliché awareness.
  Adapted from its prescriptive format to fit this system's descriptive approach.

- **Nielsen Norman Group** — usability research on error message placement, empty states,
  progressive disclosure, and touch target sizing. Multiple articles across nngroup.com.

- **WCAG 2.1 / 2.2** — accessibility guidelines informing focus visibility requirements,
  touch target minimums, and color-independence for error states.
